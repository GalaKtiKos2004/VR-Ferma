# VR Ферма (VR-Ferma)

**Cozy-game симулятор фермера для VR и ПК**

Уютный фермерский симулятор, созданный на Unity с использованием XR Interaction Toolkit. Игра основана на визуальной составляющей и приятном взаимодействии с окружающей средой: посев растений, кормление животных, уход за грядками.

## Особенности

- **Жанр**: cozy-game (расслабляющий геймплей)
- **Платформа**: Unity 2022.3+, XR Interaction Toolkit 3.1.2
- **Сеттинг**: конец XX века, фермы в США
- **Аудитория**: дети 6–10 лет и взрослые
- **Управление**: VR (шлем + контроллеры) **или** ПК (WASD + мышь)

### Основной геймплей
- Выращивание растений (морковь, помидоры, тыква, кукуруза)
- Уход за животными (курица с моделью из `Assets/Models`)
- Обработка грядок (грабли, тяпка)
- Полив из колодца/бочки
- Система обучения (этапы 0–4 согласно дизайн-документу)
- Достижения за первый урожай, уход, любовь к животным

## Быстрый старт

### Автоматическая настройка (рекомендуется)
1. Откройте Unity Editor
2. Откройте сцену `Assets/Scenes/SampleScene.unity` (или создайте новую)
3. В меню: **`VR Ferma → Full Auto Setup`**
4. Нажмите **Play**

Готово! Всё настроено автоматически: менеджеры, UI, земля, вода, грядки, инструменты, животные.

### Что делает Full Auto Setup
- Создаёт все менеджеры игры (GameManager, CropManager, AnimalManager и т.д.)
- Создаёт UI (деньги, подсказки, таймер)
- Размещает модели из `Assets/Models` (сарай, грядки, грабли, тяпка, лейка, бочка, ведро)
- Ставит префабы (семена, курица, торговец)
- Настраивает VR и Non-VR режимы
- Исправляет "розовые" материалы (URP)

## Управление

### VR режим (шлем + контроллеры)
- **Взять объект** — Grip на контроллере
- **Активировать** — Trigger (взять семена из мешка, поливать)
- **Движение** — физическое перемещение в пространстве

### Non-VR режим (ПК: клавиатура + мышь)
- **WASD** или **Стрелки** — движение
- **Мышь** — поворот камеры
- **ЛКМ** — взаимодействие (взять/посадить/собрать/погладить)
- **ESC** — разблокировать курсор

**Режимы инструментов (Non-VR):**
- **1** — грабли (взрыхлить грядку)
- **2** — тяпка (удалить сорняки)
- **3** — семена (посадить морковь)
- **4** — лейка (наполнить/полить)
- **5** — зерно (покормить курицу)

## Обучение (согласно дизайн-документу)

Обучение проходит по этапам **0–4** с пошаговыми подсказками и подсветкой объектов.

### Этап 0: Заставка и введение
- Игрок появляется в центре фермы
- Камера плавно показывает ключевые объекты: сарай, грядки, колодец, курицу
- Текст: "Добро пожаловать на твою новую ферму!"

### Этап 1: Первое растение (Базовый цикл «Посев → Урожай»)
**Задача: «Вырасти свою первую морковку!»**

1. Подсвечивается **Сарай** → "Возьмите грабли и взрыхлите грядку"
2. Игрок берёт **грабли** → подходит к **грядке** → вскапывает (2–3 действия)
3. Снова подсвечивается **Сарай** → "Возьмите пакет с семенами"
4. Игрок берёт **семена** → сажает на грядку → появляется **росток** (1-я стадия)
5. Подсвечивается **Лейка** → "Возьмите лейку"
6. Подсвечивается **Колодец** (бочка) → "Наполните лейку" (звук зачерпывания)
7. Игрок поливает росток → срабатывают **частицы воды** → росток переходит на **2-ю стадию** (кустик)
8. **Таймер: "Ваша морковка подрастет через 30 секунд"**
9. Через 30 сек → звук **"ding!"** → растение переходит в **3-ю стадию** (зрелый овощ)
10. Игрок собирает урожай → **"+1 Морковка"** → достижение **"Первый урожай!"**

### Этап 2: Знакомство с животными (Эмоциональная связь)
**Задача: «Познакомься с обитателями фермы!»**

1. Игрок подходит к **курице**
2. **Погладить** → короткая анимация, контроллер вибрирует, курица издаёт довольный звук, появляется **сердечко** → достижение **"Неизменная любовь!"**
3. Подсвечивается **Ведро с зерном** → "Возьмите горсть зерна"
4. **Покормить** → игрок подносит зерно к курице, анимация поедания, сердечко → достижение **"Ай ай ай, первая прикормка!"**

### Этап 3: Первое испытание (Введение механики ухода)
**Задача: «Подготовьте новую грядку к посадке!»**

1. После сбора первой морковки на соседней грядке **появляются сорняки и комки земли**
2. "Грядка заросла! Возьмите грабли из Сарая"
3. Игрок берёт **грабли** → разравнивает землю (2–3 взмаха) → грядка становится ровной
4. "Теперь возьмите тяпку, чтобы удалить сорняки"
5. Игрок берёт **тяпку** → убирает сорняки (2–3 взмаха) → грядка становится чистой → достижение **"Садовый мастер!"**

### Этап 4: Закрепление и свобода
**Финальная задача: "Теперь вы настоящий фермер! Посадите еще 2 морковки и не забудьте про курицу!"**

- Игрок знает весь цикл: взять семена → посадить → полить → собрать
- Знает, что грядки требуют ухода (грабли/тяпка)
- Знает, что животным нужно внимание
- **Все подсказки отключаются** → игрок действует самостоятельно

## Достижения (согласно дизайн-документу)

### Достижения за урожай
- **Первый урожай!** — собери свою первую морковку
- **Садовый мастер!** — очисти грядку от сорняков и подготовь её к посадке

### Достижения за животных
- **Неизменная любовь!** — погладь курочку
- **Ай ай ай, первая прикормка!** — покорми курочку зерном из ведра

## Как играть

### VR режим
1. **Взять инструмент/предмет** — Grip на контроллере
2. **Взрыхлить грядку** — возьмите грабли → подойдите к грядке → взмахните 2–3 раза
3. **Взять семена** — активируйте мешок (Trigger) → физическое семя появится в руке
4. **Посадить** — бросьте семя на взрыхлённую грядку
5. **Наполнить лейку** — поднесите лейку к бочке (trigger зона)
6. **Полить** — активируйте лейку (Trigger) → направьте на росток
7. **Собрать урожай** — кликните на зрелое растение
8. **Погладить курицу** — кликните на курицу (первый раз)
9. **Взять зерно** — кликните на ведро
10. **Покормить курицу** — кликните на курицу (второй раз, с зерном)

### Non-VR режим (ПК)
1. **Движение** — WASD или стрелки
2. **Поворот** — мышь
3. **Взять инструмент** — ЛКМ по граблям/тяпке/ведру или клавиши `1–5`
4. **Взрыхлить/убрать сорняки** — режим грабли/тяпка → ЛКМ по грядке
5. **Взять семена** — ЛКМ по мешку с семенами (или клавиша `3`)
6. **Посадить** — режим семян → ЛКМ по взрыхлённой грядке
7. **Наполнить лейку** — ЛКМ по бочке (режим лейки `4`)
8. **Полить** — режим лейки → ЛКМ по ростку
9. **Собрать урожай** — ЛКМ по зрелому растению
10. **Погладить/покормить** — ЛКМ по курице (для кормления нужно сначала взять зерно — ЛКМ по ведру или `5`)

## Решение проблем

### "Full Auto Setup ничего не делает"
- Убедитесь, что вы **не в Prefab Mode** (откройте Scene view)
- Проверьте Console на ошибки
- Попробуйте пустую сцену: `File → New Scene` → `VR Ferma → Full Auto Setup`

### "Розовые модели" (курица, трейдер, ведро)
- Нажмите `VR Ferma → Setup Scene / Apply Sample Fixes`
- Это заменит несовместимые шейдеры на URP/Lit

### "Управление с клавиатуры не работает"
- Убедитесь, что `Non-VR Camera` **активна** в Hierarchy
- Кликните ЛКМ по окну Game, чтобы захватить курсор
- Проверьте `Edit → Project Settings → Player → Active Input Handling` → должен быть "Input Manager (Old)" или "Both"

### "Растение не растёт"
- Убедитесь, что вы **полили** росток (стадия 2 = кустик)
- Дождитесь 30 секунд (отображается таймер в подсказке)
- При созревании раздастся звук "ding!"

### "Не могу покормить курицу"
- Сначала **погладьте** курицу (первый клик)
- Затем **возьмите зерно** из ведра (Non-VR: ЛКМ по ведру или клавиша `5`)
- Затем **покормите** (Non-VR: ЛКМ по курице)
