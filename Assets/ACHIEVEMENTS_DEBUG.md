# Диагностика достижений для животных

## Проблема: новые достижения не отображаются

### Шаг 1: Проверьте настройки в Unity Inspector

1. Найдите объект с компонентом `AchievementManager` в сцене
2. В Inspector проверьте секцию **"Спрайты достижений - Животные"**:
   - `First Love Sprite` → должен быть назначен `first_love.png`
   - `First Eat Sprite` → должен быть назначен `first_eat (2).png`
   - `Farmer Love Sprite` → должен быть назначен `farmer_love.png`
   - `Animal Happy Sprite` → должен быть назначен `animal_happy.png`
   - `Master Animal Sprite` → должен быть назначен `master_animal.png`
   - `All Achievements Sprite` → должен быть назначен `all.png`

3. Проверьте, что **`Achievement UI`** назначен в поле `Achievement UI`

### Шаг 2: Проверьте консоль Unity

При взаимодействии с животными в консоли должны появляться сообщения:
- `[Achievement] RegisterPet вызван для [имя животного]`
- `[Achievement] RegisterFeed вызван для [имя животного]`
- `[Achievement] Разблокировано: first_pet` (или `first_feed`)

Если этих сообщений нет:
- Проверьте, что на животных есть компонент `Animal`
- Проверьте, что `AchievementManager.Instance` не null

### Шаг 3: Проверьте предупреждения

Если в консоли есть предупреждения:
- `Спрайт для достижения [id] не найден!` → назначьте спрайт в Inspector
- `AchievementUI не назначен!` → назначьте UI компонент в Inspector
- `RegisterPet/RegisterFeed вызван с null животным!` → проверьте, что животное существует

### Шаг 4: Тестирование

1. **Первое поглаживание:**
   - Погладьте любое животное
   - Должно появиться достижение `first_pet`

2. **Первое кормление:**
   - Возьмите зерно из ведра
   - Покормите любое животное
   - Должно появиться достижение `first_feed`

3. **Все животные:**
   - Погладьте/покормите ВСЕХ животных на сцене
   - Должны появиться достижения `all_pets` и `all_feeds`

### Шаг 5: Сброс достижений (если нужно)

Если нужно сбросить все достижения для тестирования:
- В Unity Editor: `VR-Ferma → Сбросить достижения` (если есть такая опция)
- Или в коде: вызовите `AchievementManager.Instance.ResetAchievements()`

## Частые проблемы

1. **Спрайты не назначены** → назначьте все спрайты в Inspector
2. **AchievementUI не назначен** → найдите объект с `AchievementUI` и назначьте его
3. **Животные не найдены** → убедитесь, что на сцене есть объекты с компонентом `Animal`
4. **Достижения уже разблокированы** → проверьте в консоли сообщение "уже разблокировано"
