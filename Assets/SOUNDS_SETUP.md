# Настройка звуков в Unity

## Добавленные звуки

### Инструменты

1. **Грабли (Rake)**
   - `Tilling Sound` → `Sounds/dig.mp3`

2. **Тяпка (Hoe)**
   - `Tilling Sound` → `Sounds/tyapka.mp3`

3. **Лейка (WateringCan)**
   - `Watering Sound` → `Sounds/running-water.mp3`

### Животные (Animal)

1. **Кормление**
   - `Eat Sound` → `Sounds/bite_cartoon_-_big_chomp.mp3` (для всех животных)

2. **Поглаживание** (для каждого животного свой звук)
   - **Курица**: `Pet Sound` → `Sounds/курица.mp3`
   - **Корова**: `Pet Sound` → `Sounds/корова.mp3`
   - **Коза**: `Pet Sound` → `Sounds/коза.mp3`
   - **Свинья**: `Pet Sound` → `Sounds/свинья.mp3`

## Как настроить в Unity

### Для инструментов:

1. Выберите объект с инструментом на сцене (или префаб)
2. В Inspector найдите компонент `Rake`, `Hoe` или `WateringCan`
3. В секции "Звуки" перетащите соответствующий звук из папки `Assets/Sounds`

### Для животных:

1. Выберите животное на сцене (или префаб)
2. В Inspector найдите компонент `Animal`
3. В секции "Звуки":
   - `Eat Sound` → перетащите `bite_cartoon_-_big_chomp.mp3`
   - `Pet Sound` → перетащите соответствующий звук животного:
     - Для куриц → `курица.mp3`
     - Для коров → `корова.mp3`
     - Для коз → `коза.mp3`
     - Для свиней → `свинья.mp3`

## Примечания

- Если `Pet Sound` не назначен, будет использоваться `Happy Sound` как запасной вариант
- Все звуки автоматически воспроизводятся при соответствующих действиях
- Звук поливки (`running-water.mp3`) будет зациклен во время полива
