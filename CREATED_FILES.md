# Созданные файлы для простой фермерской игры

## 📁 Структура созданных файлов

### Игровые скрипты (Assets/Scripts/)

#### 🌱 Система растений и грядок

**PlantBed.cs** - Грядка для посадки растений
- Состояния: сухая/политая
- Посадка растений
- Сбор урожая
- Визуальные эффекты (смена материала)
- Звуки полива и посадки

**Plant.cs** - Растение с системой роста
- Автоматический рост по таймеру
- Несколько стадий роста (настраивается)
- Требует воды для роста
- Поддержка визуальных стадий (разные модели)
- Проверка зрелости для сбора

#### 💧 Система полива

**WateringCan.cs** - Лейка для полива
- Вместимость воды (настраивается)
- Расход воды при поливе
- Наполнение у источников воды
- Particle System для эффекта воды
- Поддержка VR и Non-VR режимов
- Звуки полива и наполнения

**WaterSource.cs** - Источник воды (бочка, колодец)
- Бесконечный или ограниченный источник
- Визуальный уровень воды
- Эффекты при наборе воды
- Звук зачерпывания воды

#### 🐔 Система животных

**Animal.cs** - Животное на ферме
- Система счастья (0-100)
- Автоматическое уменьшение счастья
- Кормление и поглаживание
- Производство ресурсов (яйца, молоко)
- Состояния: голодное/довольное
- Визуальные эффекты (сердечки)
- Звуки (довольное, голодное, еда)
- Поддержка анимаций

**FeedingTrough.cs** - Кормушка для животных
- Хранение корма
- Автоматическое кормление животных в радиусе
- Наполнение кормушки
- Визуализация уровня корма
- Звуки наполнения и поедания

#### 🎮 Управление и менеджеры

**SimpleGameManager.cs** - Менеджер игры (Singleton)
- Учёт ресурсов (морковь, помидоры, яйца)
- Система монет
- UI подсказки
- Игровое время
- Обновление UI

**NonVRPlayerController.cs** - Управление игроком без VR
- Движение (WASD + Shift для бега)
- Управление камерой (мышь)
- Система взаимодействия (E / ЛКМ)
- Взятие и использование лейки
- Взаимодействие с грядками и животными
- Захват/освобождение курсора

**VRInteractor.cs** - VR взаимодействие
- Система лучей (ray casting)
- Взаимодействие с объектами
- UI подсказки
- Поддержка XR Interaction Toolkit

**SimpleInteractable.cs** - Универсальный интерактивный объект
- UnityEvent для настройки в Inspector
- Cooldown между взаимодействиями
- Подсветка при наведении
- Звуки взаимодействия
- Настраиваемый текст подсказки

#### 🛠️ Editor инструменты

**SimpleFarmSetup.cs** (Assets/Scripts/Editor/)
- **Меню "Ферма → Создать простую ферму"** - автоматическая настройка
- Создание игрока с камерой и управлением
- Создание GameManager
- Создание земли (Plane)
- Размещение грядок (4 штуки)
- Создание лейки и бочки с водой
- Размещение животных (2 курицы)
- Настройка освещения
- Создание UI Canvas с подсказками
- Добавление необходимых тегов (Water)
- **Меню "Ферма → Очистить сцену"** - удаление всех объектов

## 🔗 Связи между компонентами

### Основной игровой цикл

```
Player (NonVRPlayerController)
    ↓ взаимодействие
WateringCan
    ↓ наполнение у
WaterSource (бочка)
    ↓ полив
PlantBed
    ↓ посадка
Plant
    ↓ рост
Plant (взрослое)
    ↓ сбор
SimpleGameManager (ресурсы + монеты)
```

### Система животных

```
Player
    ↓ поглаживание/кормление
Animal
    ↑ автокормление из
FeedingTrough
    ↑ наполнение игроком
```

### Менеджеры и UI

```
SimpleGameManager (Singleton)
    ↓ обновляет
UI (Canvas + TextMeshPro)
    ↓ показывает
Ресурсы, Монеты, Подсказки
```

## 🎯 Быстрая справка

### Основные классы

| Класс | Назначение | Ключевые методы |
|-------|-----------|----------------|
| `PlantBed` | Грядка | `Water()`, `PlantSeed()`, `Harvest()` |
| `Plant` | Растение | `GiveWater()`, `IsFullyGrown()` |
| `WateringCan` | Лейка | `Refill()`, `IsEmpty()` |
| `Animal` | Животное | `Feed()`, `Pet()`, `IsHungry()` |
| `SimpleGameManager` | Менеджер | `AddCarrot()`, `ShowHint()` |
| `NonVRPlayerController` | Игрок | автоматическое управление |

### Основные параметры

**Plant:**
- `growthTime` - время роста (секунды)
- `maxGrowthStage` - количество стадий

**Animal:**
- `maxHappiness` - максимальное счастье
- `happinessDecayRate` - скорость уменьшения
- `feedAmount` - сколько даёт кормление
- `petAmount` - сколько даёт поглаживание

**WateringCan:**
- `maxWater` - вместимость
- `wateringRange` - дистанция полива
