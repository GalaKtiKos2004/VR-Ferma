# Журнал изменений - Система обучения

## Добавленные файлы

### Основные скрипты обучения

1. **TutorialManager.cs** - Главный менеджер системы обучения
   - Управляет 8 этапами обучения
   - Отслеживает прогресс игрока
   - Управляет подсветкой объектов
   - Показывает подсказки на экране
   - Сохраняет прогресс в PlayerPrefs

2. **TutorialHighlight.cs** - Компонент подсветки объектов
   - Создаёт визуальную подсветку вокруг объектов
   - Пульсирующая анимация для привлечения внимания
   - Автоматически адаптируется под любые 3D объекты
   - Поддержка эмиссии для свечения

### Новые инструменты и объекты

3. **Rake.cs** - Грабли для взрыхления грядок
   - Взрыхление грядок перед посадкой
   - Поддержка VR и Non-VR режима
   - Звуковые эффекты
   - Интеграция с TutorialManager

4. **SeedBag.cs** - Пакет с семенами
   - Посадка семян на взрыхлённые грядки
   - Поддержка разных типов семян
   - Счётчик семян (можно отключить для бесконечных)
   - Поддержка VR и Non-VR режима
   - Интеграция с TutorialManager

### Утилиты

5. **TutorialDebug.cs** - Инструменты отладки
   - Клавиши для быстрого тестирования (R, N, I)
   - Сброс прогресса обучения
   - Пропуск текущего шага
   - Визуальный дебаг UI в углу экрана
   - Context Menu для быстрого доступа

### Документация

6. **TUTORIAL_README.md** - Полная документация
   - Подробное описание всех этапов
   - Инструкции по настройке в Unity
   - Советы по расширению системы
   - Решение проблем

7. **TUTORIAL_QUICKSTART.md** - Быстрый старт
   - Пошаговая инструкция на 15 минут
   - Минимальная конфигурация
   - Быстрое решение проблем
   - Структура сцены

8. **TUTORIAL_CHANGELOG.md** - Этот файл
   - Список всех изменений
   - Описание новых возможностей

## Изменённые файлы

### PlantBed.cs - Расширенная функциональность

**Добавлено:**
- `bool isTilled` - состояние "взрыхлена"
- `Till()` - метод взрыхления грядки
- Обновлённый `PlantSeed()` - теперь создаёт росток без автоматического роста
- Обновлённый `Water()` - запускает рост уже посаженного растения
- `IsTilled()` - геттер для проверки состояния
- Интеграция с TutorialManager (уведомления о событиях)
- Обновлённая визуализация состояний

**Изменена логика:**
- Раньше: вода → растение сразу растёт
- Теперь: взрыхлить → посадить → полить → растёт

### WateringCan.cs - Интеграция с обучением

**Добавлено:**
- `bool wasGrabbed` - флаг для отслеживания первого взятия
- `OnGrabbed()` - уведомление TutorialManager
- Подсказка при наполнении лейки
- Проверка взятия в Update()

### SimpleGameManager.cs - Без изменений

Используется существующий `ShowHint()` для отображения подсказок.

## Известные ограничения

1. Обучение работает только с одной грядкой
2. Нет проверки последовательности действий (можно взять всё сразу)
3. Подсветка может работать медленно на слабых устройствах
4. Non-VR режим требует доработки для полного функционала
