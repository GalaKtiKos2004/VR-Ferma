# 🌱 Система обучения VR-Ferma

## 📋 Краткое описание

Полноценная система обучения для VR фермы, которая проводит игрока через первый цикл выращивания морковки от взрыхления грядки до сбора урожая.

## ✨ Возможности

- ✅ **8 интерактивных этапов** обучения
- ✅ **Визуальная подсветка** объектов с пульсацией
- ✅ **Текстовые подсказки** на экране
- ✅ **Звуковое сопровождение** всех действий
- ✅ **Поддержка VR и Non-VR** режимов
- ✅ **Автосохранение** прогресса
- ✅ **Инструменты отладки** для разработчиков
- ✅ **Editor утилита** для быстрой настройки

## 🎯 Этапы обучения

1. 🔧 Взять грабли из сарая
2. 🌾 Взрыхлить грядку
3. 📦 Взять пакет с семенами
4. 🌱 Посадить семя
5. 🚰 Взять лейку
6. 💧 Наполнить лейку в колодце
7. 💦 Полить росток
8. 🥕 Собрать урожай (через 30 секунд)

## 🚀 Быстрый старт

### Автоматическая настройка (рекомендуется)

1. В Unity: **VR-Ferma → Tutorial Setup Helper**
2. Нажмите **"🚀 АВТОМАТИЧЕСКАЯ НАСТРОЙКА ВСЕГО"**
3. Следуйте инструкциям в диалогах
4. Добавьте XR Grab Interactable к граблям и семенам
5. Запустите сцену!

### Ручная настройка

См. **TUTORIAL_QUICKSTART.md** для подробных инструкций.

## 🎮 Управление

### VR режим
- **Взять объект** - Grab на контроллере
- **Использовать** - Trigger на контроллере

### Non-VR режим
- **Взять объект** - E или ЛКМ
- **Использовать** - ЛКМ

### Отладка (клавиши)
- **R** - Сбросить обучение
- **N** - Пропустить текущий шаг
- **I** - Показать информацию

```
Scene
├─ TutorialManager (с компонентами TutorialManager + TutorialDebug)
├─ Barn
│   ├─ Rake (Rake + XRGrabInteractable)
```

## 🔧 Настройка в 3 шага

### Шаг 1: Откройте Editor утилиту
```
Unity → VR-Ferma → Tutorial Setup Helper
```

### Шаг 2: Автоматическая настройка
```
Нажмите "🚀 АВТОМАТИЧЕСКАЯ НАСТРОЙКА ВСЕГО"
```

### Шаг 3: Завершите настройку
```
1. Добавьте XR Grab Interactable к Rake и SeedBag
2. Настройте события OnGrabbed() в XR Grab Interactable
3. Назначьте слой PlantBed грядкам
4. Запустите сцену!
```

## 🐛 Решение проблем

### Обучение не запускается
```
1. Проверьте Tutorial Enabled = ✓ в TutorialManager
2. Сбросьте: VR-Ferma → Tutorial Setup Helper → "Сбросить обучение"
3. Проверьте Console на ошибки
```

### Подсветка не работает
```
1. Проверьте что объекты имеют Renderer
2. Проверьте что TutorialManager запущен (Start вызвался)
```

### Грабли/семена не работают
```
1. Проверьте слой PlantBed на грядках
2. Проверьте Tilling Range / Planting Range (должно быть ~2)
3. Проверьте что грядка имеет Collider
```
