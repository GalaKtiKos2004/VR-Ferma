# Система обучения VR-Ferma

## Описание

Система обучения проводит игрока через первый полный цикл фермерства: от взрыхления грядки до сбора урожая морковки.

## Этапы обучения

### Этап 1: Взять грабли
- Подсвечивается Сарай и грабли
- Подсказка: "Возьмите граблю из сарая и взрыхлите грядку"
- Игрок берёт грабли

### Этап 2: Взрыхлить грядку
- Подсвечивается грядка
- Подсказка: "Нажмите и вскопайте грядку"
- Игрок использует грабли на грядке
- Грядка меняет цвет, показывая что взрыхлена

### Этап 3: Взять семена
- Подсвечивается Сарай и пакет с семенами
- Подсказка: "Подойдите и возьмите пакет с семенами моркови"
- Игрок берёт пакет с семенами

### Этап 4: Посадить семя
- Подсвечивается грядка
- Подсказка: "Подойдите к грядке и нажмите, чтобы посадить семя"
- Игрок использует семена на грядке
- Появляется маленький зелёный росток (стадия 1)

### Этап 5: Взять лейку
- Подсвечивается лейка
- Подсказка: "Нажмите, чтобы взять лейку"
- Игрок берёт лейку

### Этап 6: Наполнить лейку
- Подсвечивается колодец
- Подсказка: "Подойдите к колодцу и наполните лейку водой"
- Игрок подходит к колодцу
- Звук зачерпывания воды, лейка визуально наполняется

### Этап 7: Полить росток
- Подсвечивается грядка с ростком
- Подсказка: "Подойдите к ростку и нажмите, чтобы полить его"
- Игрок поливает росток
- Звуковой эффект и частицы воды
- Росток начинает расти (стадия 2)

### Этап 8: Собрать урожай
- Таймер: "Ваша морковка подрастёт через 30 секунд"
- Через 30 секунд звук "ding!" и растение созревает (стадия 3)
- Подсказка: "Урожай созрел! Нажмите, чтобы собрать морковку!"
- Игрок собирает урожай
- Анимация "+1 Морковка"
- Достижение: "Первый урожай!"

## Настройка в Unity

### 1. Создайте объект Tutorial Manager

1. В сцене создайте пустой GameObject с именем "TutorialManager"
2. Добавьте компонент `TutorialManager`
3. Настройте ссылки на объекты:
   - **Barn** - сарай (здание со склада)
   - **Rake** - грабли (инструмент)
   - **Seed Bag** - пакет с семенами
   - **Tutorial Plant Bed** - обучающая грядка (PlantBed)
   - **Watering Can** - лейка
   - **Well** - колодец (источник воды)

4. Настройте параметры подсветки:
   - **Highlight Color** - цвет подсветки (по умолчанию: жёлтый, alpha 0.5)
   - **Pulse Speed** - скорость пульсации подсветки (по умолчанию: 2)

### 2. Настройте грабли (Rake)

1. Создайте объект граблей (например, куб или модель)
2. Добавьте компонент `Rake`
3. Добавьте компонент `XRGrabInteractable` (для VR) или `SimpleInteractable` (для non-VR)
4. Настройте параметры:
   - **Tilling Range** - дальность взрыхления (2 метра)
   - **Plant Bed Layer** - слой грядок
   - **Tilling Sound** - звук взрыхления

5. В событиях `XRGrabInteractable`:
   - **Select Entered** → добавьте вызов метода `Rake.OnGrabbed()`

### 3. Настройте пакет с семенами (SeedBag)

1. Создайте объект пакета с семенами
2. Добавьте компонент `SeedBag`
3. Добавьте компонент `XRGrabInteractable` (для VR)
4. Настройте параметры:
   - **Seed Type** - "Морковь"
   - **Seed Count** - 10
   - **Infinite Seeds** - true (для обучения)
   - **Planting Range** - дальность посадки (2 метра)
   - **Plant Bed Layer** - слой грядок
   - **Planting Sound** - звук посадки

5. В событиях `XRGrabInteractable`:
   - **Select Entered** → добавьте вызов метода `SeedBag.OnGrabbed()`

### 4. Настройте лейку (WateringCan)

Лейка уже должна быть настроена, но убедитесь что:

1. Есть компонент `WateringCan`
2. Есть компонент `XRGrabInteractable`
3. В Update() вызывается `OnGrabbed()` при взятии лейки

### 5. Настройте колодец (WaterSource)

1. Убедитесь что у колодца есть компонент `WaterSource`
2. Убедитесь что у колодца тег "Water"
3. Добавьте TriggerCollider для взаимодействия с лейкой

### 6. Настройте грядку (PlantBed)

Грядка уже обновлена и поддерживает все необходимые функции:
- `Till()` - взрыхление
- `PlantSeed()` - посадка семян
- `Water()` - полив
- `Harvest()` - сбор урожая

### 7. Настройте слои (Layers)

Создайте слой "PlantBed" и назначьте его всем грядкам.

### 8. UI подсказок

Система использует `SimpleGameManager.ShowHint()` для отображения подсказок. Убедитесь что:
1. В сцене есть SimpleGameManager
2. У него настроен TextMeshProUGUI для hintText
3. Текст отображается на Canvas

## Тестирование

1. Запустите сцену
2. Должна появиться подсказка "Добро пожаловать на ферму! Начнём обучение."
3. Сарай и грабли должны подсвечиваться жёлтым с пульсацией
4. Следуйте подсказкам на экране

## Отключение обучения

Обучение автоматически сохраняет прогресс в PlayerPrefs. Чтобы сбросить:

```csharp
PlayerPrefs.DeleteKey("TutorialCompleted");
```

Или в компоненте TutorialManager снимите галочку "Tutorial Enabled".

## Расширение системы

### Добавление новых этапов

1. Добавьте флаги в TutorialManager (например, `private bool newStepCompleted = false;`)
2. Создайте метод `StartStepX_Description()`
3. Создайте публичный метод `OnStepXCompleted()`
4. Добавьте вызов в предыдущий этап через `StartCoroutine(WaitAndStartStepX())`

### Добавление новых объектов для подсветки

```csharp
[SerializeField] private GameObject newObject;

// В InitializeHighlights():
AddHighlight(newObject);

// В нужном этапе:
HighlightObject(newObject);
// ...
UnhighlightObject(newObject);
```

## Советы по оптимизации

1. Подсветка создаёт дополнительные объекты - используйте только во время обучения
2. После завершения обучения компоненты TutorialHighlight можно отключить
3. Для больших объектов используйте простую подсветку (сфера вместо копии меша)

## Локализация

Все текстовые сообщения находятся в TutorialManager. Для локализации:
1. Создайте словарь сообщений
2. Замените строки на ключи
3. Загружайте тексты из файла в зависимости от языка

## Известные проблемы

1. **Подсветка не работает на объектах без Renderer** - будет создана простая сферическая подсветка
2. **VR триггеры могут не срабатывать** - проверьте Input System и XR Input
3. **Non-VR режим** - используйте ЛКМ вместо VR триггера

## Поддержка

Если возникли проблемы:
1. Проверьте Console на ошибки
2. Убедитесь что все ссылки в Inspector настроены
3. Проверьте что слои и теги настроены правильно
