# Исправления проблем

## ✅ Исправлено: Земля моргает зеленым цветом

### Проблема
Земля (Ground) мигает или мерцает зеленым цветом - это **z-fighting**.

### Причина
- Несколько объектов Plane на одной высоте (0)
- Грядки слишком близко к земле
- Два или больше Ground объектов накладываются друг на друга

### Решение
Обновлен скрипт `SimpleFarmSetup.cs`:

1. **Удаление всех старых Plane** перед созданием новых
2. **Ground опущен на -0.05** (вместо 0)
3. **Грядки подняты на 0.25** (вместо 0.1)

### Как исправить

#### Вариант 1: Пересоздать сцену (рекомендуется)

1. В Unity Editor выберите: **`Ферма → Очистить сцену`**
2. Подтвердите удаление
3. Выберите: **`Ферма → Создать простую ферму`**
4. Нажмите Play

#### Вариант 2: Исправить вручную

1. Найдите все объекты с именем "Plane" или "Ground" в Hierarchy
2. Удалите лишние (оставьте только один)
3. Выберите оставшийся Ground
4. В Inspector установите Position Y = **-0.05**
5. Найдите все грядки (PlantBed_1, PlantBed_2, и т.д.)
6. Для каждой установите Position Y = **0.25** или выше

#### Вариант 3: Быстрое решение

Если не хотите пересоздавать сцену:

1. Выберите все Plane объекты в Hierarchy
2. Удалите лишние (Ctrl + Delete)
3. Один Ground оставьте и опустите на Y = -0.05

## Другие возможные проблемы

### Объекты "проваливаются" сквозь землю

**Решение:**
- Убедитесь, что у Ground есть Mesh Collider
- Проверьте, что у игрока есть Character Controller
- Установите Ground Layer на "Default"

### Розовые материалы на моделях

**Решение:**
1. Выберите объект с розовым материалом
2. В Inspector найдите Renderer → Materials
3. Создайте новый материал: `Assets → Create → Material`
4. Shader: `Universal Render Pipeline/Lit`
5. Настройте цвет
6. Перетащите на объект

### Не работает взаимодействие

**Решение:**
- Кликните ЛКМ в окне Game для захвата курсора
- Проверьте, что у объектов есть Collider
- Убедитесь, что Layer Mask настроен в NonVRPlayerController
